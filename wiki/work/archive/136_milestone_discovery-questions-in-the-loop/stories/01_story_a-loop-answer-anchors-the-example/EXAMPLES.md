## R1 · An answered loop question anchors the token its question opens with
- E1 · The run of 136/01 asked "136/01 Q1 · Discovery question …", answered "No" from the terminal → Q1 answered and E6 stated Q1 report no unanchored finding [proposed]
- E2 · The same ask parked at the bound, never answered → E6 stated Q1 is reported unanchored [proposed]
- E3 · The answer is written while the run is still running, and the resumed session runs the doctor → anchored [proposed]

## R2 · A loop question that cannot say which token it answered anchors none
- E4 · One ask holding "136/01 Q1 · …" and, after a blank line, "136/01 Q2 · …", answered "yes, then no" → neither Q1 nor Q2 is anchored [proposed]
- E5 · An ask opening "Decision needed: …" with no token → anchors nothing, and the reader does not fail [proposed]

## R3 · An answer counts from every channel the loop records it on
- E6 · An allowlisted user replies to the Discord message → the answer anchors the token, and the record names the Discord account [stated Q1]
- E7 · The operator answers in the board's reply box → the answer anchors the token [stated Q1]
