# Build brief

Extend the existing doctor's command boundary, where citation history is already
read and workspace findings are appended after item scope filtering. Retain one
history read and pass the same map into both consumers. The small probe owns
wiki enumeration, local source classification and finding construction; the
shared grammar and resolver own the interpretations they already implement.

Use temporary projects to prove missing/current/moved/deleted citations, full
path prefixes, scoped visibility, read failures and cwd independence. Exercise
the actual CLI for normal and strict exit behavior. Register the architecture
control with its subject and demonstrate a failing resolver bypass and a
disconnected command call. Run the story's impacted test selection and declared
control before validate/doctor review.

No memory rewrite, recursive work-stream sweep, source execution, new package,
resolver policy change or control-gate expansion belongs to this story.
