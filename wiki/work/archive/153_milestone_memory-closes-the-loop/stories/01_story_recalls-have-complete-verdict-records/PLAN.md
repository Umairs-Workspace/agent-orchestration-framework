# Build brief

## Mechanism

The memory seam routes a completed observation to the work-owned ledger transition through core injection. The parser admits the additive kind; all existing raw consumers keep explicit kind selection. Idempotence is enforced at the append boundary, including concurrent same-id submissions. Retirement removes the unwired digest surface without changing the backend interface.
