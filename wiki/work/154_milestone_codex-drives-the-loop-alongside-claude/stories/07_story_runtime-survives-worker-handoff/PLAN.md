# 154/07 · Workers retain the selected runtime and assets — build plan

Advisory to the builder; the task features are the acceptance contract.

## Mechanism

Carry the existing execution envelope through declaration and session handoffs. Preflight profile capability, prepare selected generated files from lock ownership, and keep trust runtime-specific. Resume and cancellation use the same adapter boundary as local execution.

## Verification step

Use a control/worker fixture with differing local defaults and a worktree whose generated assets are ignored by Git. Inspect launch inputs, refusal behavior, returned identity and reconnect resume; rerun legacy wire compatibility cases.

## Out of scope

No scheduler redesign, remote credential copying, worker enrollment or mixed-runtime phases.
