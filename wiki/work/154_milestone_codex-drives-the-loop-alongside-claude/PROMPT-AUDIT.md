# Runtime prompt audit

Inventory: 43 descriptor roles, procedures and skills. Runtime selection is automatic;
there is no free-form template profile. Common metadata/body, selected bundled variant, then
project resource overrides determine the result. Claude/OpenCode retain the common bodies;
retrospective gains the shared recall/ingest edge required by this story, repair states its
named-cause proof bound, and delegate plus the two delegation roles and three recipes retain
their CLI functionality while requiring a separately requested cross-assistant task. Native role
TOML inherits the session model unless an explicit runtime-scoped choice is rendered.
The three codex-* skills remain Claude-only cross-assistant recipes, not Codex self-delegation.
Native entries retain critical scope/ownership/gate rules. Seven high-risk entries attach only
their own procedure; the shared reference contains no other procedure body. All other entries
contain their procedure directly. Source variant sections are not all loaded into a session.
The native provider seam refuses missing independent-role or setting capabilities; model-backed
client availability and behavioral evaluation belong to later milestone proof. Fixture launches
prove routing/settings/bounds, not that a particular client exposes spawn_agent.

Removed repetition and word counts are context-load measurements only. They are NOT correctness
improvements; later repeated behavioral evaluations must establish unchanged outcomes. These
adaptations still require maintainers to update both the common contract and relevant native
section when shared obligations change. Installation is ownership guarded, not a blanket refresh.
