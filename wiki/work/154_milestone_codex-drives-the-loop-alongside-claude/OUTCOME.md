# 154 · Codex drives the AOF loop alongside Claude — Outcome

## Delivered

### Two assistants share one governed loop
AOF's existing work loop can execute and recover native Claude and Codex phases using one retained runtime choice, assistant-specific assets and common work-item gates; existing projects retain Claude as their default.

## Assumptions

- **Admitted native profile** — Codex live proof covers CLI 0.160.0, the App Server v1 profile and existing authorized access; unsupported versions or capabilities are refused explicitly.
- **Host execution capability** — the selected host must permit the required workspace writes and tools; the adapter does not grant native permission requests or switch assistants to bypass a refusal.
- **Independent review** — orchestrated reviews require an exposed supported native launcher; solo mode performs inline self-review and claims no independent context.
- **Measurement** — captured native token counts remain distinct from unavailable monetary cost, and entry size alone establishes no end-to-end speed or cost advantage.
