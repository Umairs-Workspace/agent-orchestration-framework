## Notes & decisions in flight

- **Scheduled 2026-08-16** from `PRD-acd-loop-performance.md` lever (d) — the consolidated build
  brief — substantially widened by `RESEARCH-agent-loop-economics.md`, which found that the brief is
  only half the problem. **The PRD contains nothing about prompt-cache economics**, and the cache is
  the larger half: 927k cache-create per spawn at a 12.6× price premium over the same tokens read.
- **The worktree-per-story design is the cache's antagonist.** This is worth stating plainly at
  refine because it is a genuine architectural tension, not a bug: worktrees exist because a
  partition's independence claim is not reliable (two stories an architect had partitioned as
  independent both edited one file, ×9 and ×8), and the isolation is load-bearing.
  `--exclude-dynamic-system-prompt-sections` is what lets aof keep the isolation and share the
  prefix; refine should verify that empirically before the design assumes it.
- **Do not warm the reviewer.** Recorded as out-of-scope in the SPEC and repeated here because it is
  the obvious-looking move and the evidence says it is wrong.
- **Open question for refine:** whether the brief is generated by a cheap model (Haiku, per the
  summarisation-is-30×-cheaper pattern) or assembled deterministically from `STORY.md` frontmatter.
  Deterministic assembly is cacheable and free; a model-written digest is richer. Probably both:
  deterministic skeleton, model-written "what changed and why" section.
  - **⟨resolved at refine, 2026-08-21⟩ Deterministic only, for this milestone.** ADR-002 makes the
    compiler a **pure leaf** — no I/O, no wall-clock, no model call — because the driver's export
    set is frozen at seventeen by an enforced control and because a bound (ADR-003) is only testable
    if the thing being bounded is deterministic. A model-written "what changed and why" section
    would put a spawn inside the spawn path and make the brief unreproducible run to run. The
    section list is left **open** precisely so a model-written section can be added later without
    renegotiating the ceiling; 70/03 is the first proof of that (it adds the ADR slice).

## Decisions taken at refine (2026-08-21)

Recorded per the autonomous door: default decisions taken rather than stopping, each with the
measurement behind it. The two marked **⚠** contradict the SPEC and are the ones to check first.

- **⚠ The `ARCHITECTURE.md` split is refused as written (ADR-006).** The SPEC's scope bullet asks to
  split the file per ADR. Measured here, the file is a pinned member of **four** independent reader
  surfaces — the artifact manifest (`work-artifacts.mjs`, 5 `src/` dependents), the register's frozen
  file set (`declared-id.mjs` — the fitness register *is* in this file), the controls checker, and
  memory's ADR indexing (`memory/local-indexing.mjs`, which answered this refine's own recall).
  A split is a four-surface rewrite of frozen sets that would silently drop the ADR corpus to zero.
  **The stated intent — "a story should read its slice" — ships in full** through the brief, which
  is the mechanism that exists for exactly that. Only the file-level mechanism is refused.
- **⚠ `adrs:` in story frontmatter does not exist.** The SPEC says it does ("Story frontmatter
  already declares which ADRs a story needs"). Across **201** `STORY.md` files, **zero** carry it and
  no `adr`-shaped key exists anywhere under `wiki/work/`. 70/03 **introduces** it as an optional
  additive key, exactly as `depends:` was.
- **The cache flag was verified empirically, as STATE asked.** On the installed binary
  (`claude 2.1.233`) `--exclude-dynamic-system-prompt-sections` exists and its help states it is
  *"ignored with `--system-prompt`"*. aof uses `--append-system-prompt` and **`--system-prompt`
  appears nowhere in `src/**`** — so the flag applies, and the worktree-per-story tension STATE
  flagged as genuine is resolved rather than assumed (cwd is one of the sections it relocates).
  ADR-004 turns the enabling condition into a control, because breaking it is silent.
  `--model`, `--effort` and `--resume` were verified present on the same binary.
- **The architecture budget binds at accept, not across the stream (ADR-007).** 15 milestones
  already exceed the 700-line budget (worst 3,975). Failing the sweep turns 15 `done` milestones red
  at once — chore 64's exact pathology — and milestone 55's frozen-set mechanism does not exist in
  `src/**` yet, so a design leaning on it would be leaning on nothing. This milestone's own
  `ARCHITECTURE.md` is written to the rule it sets (428 lines).
- **The session model and the role model are kept as two surfaces (ADR-005).** m30's
  `work.agents.models` is shipped and governs *rendered agent frontmatter*; this milestone adds the
  *spawn's* `--model`/`--effort`. Distinct config paths, no join.
- **Nothing is written to `src/run-store.mjs`** (17 `src/` dependents). 70 reads the record 68 made
  true and adds no key.
