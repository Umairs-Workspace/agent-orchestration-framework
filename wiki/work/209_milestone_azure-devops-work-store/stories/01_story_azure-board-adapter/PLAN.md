# 209/01 · Azure board adapter

## Mechanism

Ship the inherited Agile mappings and transport together as a copyable project example. Acquire a short-lived token through the executing account's az and use in-process HTTP for work-item requests. Validate the selected area's process metadata before mutation. The guide should make clear when a project administrator must prepare the process.

Compose the adapter's read from an ID query, detail batches and relation queries. The revisions feed has its own cursor. A patch uses the revision of the affected item. Return per-member outcomes even when Azure returns an error for the whole batch.

## Verification step

Replay recorded HTTP through the selected definition. Inspect mapped data from both ends of a 2,505-item stream and a cross-batch predecessor. Exercise the write and observation operations on the same adapter, including a 412 and a lost batch result. Use a controlled clock and fake credential broker so the replay works offline and records no credentials.
