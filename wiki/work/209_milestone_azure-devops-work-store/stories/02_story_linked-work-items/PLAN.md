# 209/02 · Linked work items

## Mechanism

Use the successful close of refinement to request publication from the selected store. Both an interactive refine and a driven refine know their phase at that point. A generic run finishing successfully is insufficient evidence that refinement completed.

Persist the publication intent and a discoverable correlation key before sending each create. Verify the returned board identity, revision, tracked values and relations before acknowledging the member. On retry, recover uncertain members from the board and use the same claim for competing writers. Keep the desired values and document home available through a process restart.

Compose the existing lifecycle and placement operations with these durable links. Renumbering changes the ref that addresses the documents. The board keeps its item ID. Dispatch archive by the selected store before selecting or moving any folders.

## Verification step

Exercise refinement against a project-owned fixture that records board requests. Lose the child create response, restart and retry. Inspect the board for one child with the intended parent, use the public work verbs to move the linked item, then open the decision from its current home. Once done, try single and bulk archive in board mode and use a local-file workspace as the positive archive control.
