# 201/02 · Every recall leaves a record, and the PO asks by title — build plan

Advisory and the builder's own. The task features are the contract.

## Mechanism

This story edits prose and nothing that runs. Two commands change, in the bundle's source and in
the authored Codex variant, and `aof work update` carries them into the tracked renders, the
manifest and the lock.

In refine, the PO's recall loses `--item <ref>` and takes the item's title, verbatim, as its
query. The capture paragraph beside it changes its scope from the item to `{}`. The architect's
half of that paragraph is untouched.

In the retrospective, each of the two recalls gains a capture, written the way continue's and
verify's are: keep the result, mint one id, write the observation to a scratch file outside every
work folder, give every returned record a verdict, submit once. Copy the shape of
continue's episodic capture for the evidence recall, because it already handles an `--all --json`
result. The sentence saying the evidence step records nothing goes, and the output note admits
the two ledger rows.

The control to extend is the one that already reads every memory invocation in the bundle. It
counts invocations (22 today, so the count moves by the two new captures), holds the retrospective
to 157's evidence rules, and asserts that the three renders match a fresh render. One of its
patterns asserts the sentence this story deletes. Replace that case with the new invariant: every
recall has a capture that names its own edge, and the roster of eight is asserted both ways.

## Verification step

Run `aof work update`, then `git status`. The only files changed should be the ones this story
declares. Then run the edge control and the recall-ledger integration feature by file.

A wrong answer looks like one of two things. A render that did not move means the Codex variant
or a mirror was missed. A changed continue, verify or shatter render means an edit strayed into a
shared paragraph.

## Out of scope

- Any change to how `--block` behaves. That is story 00, and these edges need no edit to use it.
- A `pick` field in the observation. ADR-006 rejects it.
- The hyperagent skills, which substitute a code search for recall. They are not recall edges.
- The stale citations 177 listed. They belong to `retire-graphify-memory-backend`.

## Known traps

- Markdown wraps a command across lines, and the control reads invocations over the joined body.
  An invocation that ends at a line break without its terminator is read as longer than it is.
- An invented flag fails silently at runtime: the seam's parser skips it and folds its value into
  the query. Only the static control catches it, so spell flags from the seam's own list.
- The renders are checked in with exact line endings. Let `aof work update` write them, and do not
  hand-edit a mirror.
- The memory page is also edited by story 01 (the ranking section). This story touches only the
  decision-edges table and the retrospective-evidence section.
