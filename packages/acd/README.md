# @aof/acd

Private workspace for ACD, the methodology aof installs by default. It holds the methodology's
assets and nothing else: no verb, no service, no runtime code (chore 207).

| Export | Responsibility |
| --- | --- |
| `contribution` | The one object core's methodology registry (`packages/core/src/methodology.mjs`) reads: the package whose `assets/bundle.json` is the methodology's descriptor, and the files core reads by role. |

## The assets it ships

`assets/bundle.json` declares every ACD member: the agents, the `aof:` commands, the Codex skills,
the item templates, the build-brief fragment and practice, the Codex workflow reference and its
variants, the loop records, the frozen set (`frozen-set.jsonc`) and the trigger declaration
(`triggers.jsonc`). `assets/manifest.json` catalogues the canonical render and is regenerated by
`node scripts/generate-bundle-manifest.mjs`.

Core's `assets/bundle.json` keeps the runtime plumbing every methodology needs: the session-ping,
run-heartbeat, ask-pending and artifact-sync hooks. Core reads its own descriptor first and appends
this one, then each integration's and practice's fragment.

A packaged binary reads these assets from its `bundle/` sidecar, exactly as before the move.
