- **Mocks on the project's design system (198/ADR-002, ADR-007).** `work.ui.designSystem` names the system a mock is drawn on. A brief you write asks for a mock drawn with that system's tokens and components, and the binding checklist names them. In `reference` mode the system is someone else's: what it lacks is named under `## Design-system gaps` in `DESIGN.md` and drawn with the system's existing tokens. You never ask for the system itself to be changed, in either mode; the session that draws the canvas installs the system and publishes nothing to it.
